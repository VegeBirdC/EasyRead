Chrome / Edge · 插件免费，翻译用 DeepSeek API 按量计费

译读 1.0

拖入小说 → 选输出格式 → 选是否翻译成中文 → 下载。支持 EPUB、HTML、PDF、TXT 互转。

首次安装
  1. 解压整个包，保留文件夹（不要只拿出里面的单个文件）。
  2. 浏览器地址栏打开 chrome://extensions（Edge 用 edge://extensions）。
  3. 打开右上角（Edge 在左下角）的“开发者模式” → 点“加载已解压的扩展程序”。
  4. 选择这个 extension 文件夹：
  5. 点浏览器工具栏的拼图图标，把“译读”固定到工具栏。

旧版升级：用新版 extension 里的文件覆盖原来的 extension 文件夹，在扩展管理页点“重新加载”。保持原路径不变，Key、设置和已译内容都会保留。

连接 DeepSeek（只转换格式可以跳过）
  1. 到 platform.deepseek.com 注册、充值几块钱，创建一个 API Key（sk- 开头，只显示一次，先复制好）。
  2. 点工具栏上的“译读”图标（或按 Alt+Shift+U）打开主页面，点右上角“⚙ 设置”。
  3. 粘贴 Key → 点“检测连接”，看到“✓ 连接成功”就行。模型保持 deepseek-flash 即可。
  4. 点“保存设置”。

Key 只保存在你这台电脑的浏览器里，不用发到聊天里，也不会传给除 DeepSeek 以外的任何地方。

开始转换 / 翻译
  1. 把 AO3 下载的小说（EPUB / HTML / PDF / TXT 都行，可以一次拖好几本）拖进虚线框。
  2. 选输出格式：EPUB（手机、阅读器、Apple Books、微信读书导入都用它）、HTML、TXT 或 PDF。
  3. 选翻译：不翻译 / 只要中文 / 中英对照。
  4. 点“开始”。译完会自动下载；书单里还能一键再导出成其他格式，不会重复花钱。

AO3 下载建议优先选 EPUB 或 HTML（结构最完整，斜体、章节都能保留）。PDF 只能提取文字，排版会简化。MOBI/AZW3 不支持。

预览来自模拟测试（用的是假的翻译接口）。还没有用你的真实 Key 和小说验证翻译质量与速度。
